SYS·01  //  SOURCE & ECHO METHOD

How we build the AI-prompt set we track for a client

A data pipeline, drawn the way an engineer would draw it, explained the way a marketer reads it. Many private and public sources flow in, get merged and clustered into topics, expand into the real questions AI engines ask, and are scored down to the priority set we track daily per engine. Worked on Decube, a data-governance platform.

// process · prioritizethe same rule every time, defensible to a client

The 300+ universe is narrowed by three ordered steps, run in code so the same inputs always produce the same priorities. This is the step that takes opinion out of the list.

gate → rank → diversify
1 · gate
Keep only non-branded questions where engines actually name vendors. The rest route to the content plan.
2 · rank
Order by demand × winnability × product & buyer fit. A high-intent, low-volume question can still reach the top.
3 · diversify
Spread across the funnel; collapse any two prompts that are really one bet (same answer, same sources).
emit the tracked set
